## 1. O que foi entregue

| Item | Valor |
|---|---|
| **Space público** | [`rafaelang/assistente-master-iag`](https://huggingface.co/spaces/rafaelang/assistente-master-iag) |
| **Dataset privado** (corpus) | `rafaelang/assistente-master-iag-dados` |
| **SDK / hardware / sleep** | `docker` · `cpu-upgrade` · 1 h |
| **URL da API** | `https://rafaelang-assistente-master-iag.hf.space/` |
| **Corpus em produção** | 3.517 chunks / 192 docs · texto+imagem (294 chunks v3, 22 figuras) |

A publicação segue a arquitetura de duas camadas definida em `deploy/README.md`:

```
Internet ──► Space PÚBLICO assistente-master-iag (código, SEM corpus)
               │  boot: snapshot_download (secret HF_TOKEN_READ)
               ▼
            /app/data  ◄── Dataset PRIVADO assistente-master-iag-dados
                            (data/raw + índices processed/rag*, rag_v3, slm_models)
```

- **O repo público não expõe o corpus** (direitos autorais/LGPD): o `deploy.sh`
  envia `data/raw` + índices para o dataset **privado** e o container baixa em
  runtime no boot (`deploy/entrypoint.sh`).
- **Modelos em produção = só remotos** (`AGENTE_ROTEADOR=flash`,
  `AGENTE_SIMPLES=flash`, `AGENTE_COMPLEXA=pro`); o SLM local (Qwen 1.5B GGUF)
  fica para uso local/CLI.

## 2. Custo por mil consultas (Aula 07)

Medido no fim-a-fim da v0.6 (mesmos preços usados nos avaliadores — DeepSeek
`deepseek-v4-pro` a US$ 0,27/M tokens de entrada e US$ 1,10/M de saída):

| Rota | Custo por pergunta | **Custo por 1.000 consultas** |
|---|---|---|
| **cascade (default — R2 TF-IDF/XGB local + SLM/flash na simples)** | US$ 0,00027 | **US$ 0,27** |
| frontier `pro` forçado (pior caso) | US$ 0,0015 | **US$ 1,50** |

Referência dos números (fonte: `docs/v06_evidencia.md` §2 e §4): o roteador
`cascade` decide ~85% das perguntas a **2 ms / US$ 0** (sem LLM), por isso o
custo médio é ordens de magnitude menor que o frontier. O alvo definido no
fechamento da v0.6 era **TCO ≤ US$ 0,001/Q** — o cascade (0,00027) **cumpre
com folga**; o `pro` forçado (0,0015) é documentado como teto de referência.

> Estimativa de arquitetura, não TFUE contábil: depende do mix de rotas, do
> comprimento do contexto recuperado e do preço vigente dos modelos no
> endpoint — ver `scripts/avaliadores/avaliar_cascade_v05b.py` para reproduzir
> a conta token-a-token.

## 3. Falhas encontradas no smoke test (e correções)

O teste de produção do Space expôs **três defeitos** que a suíte local não
cobria. Todos corrigidos nesta release — evidência em `docs/v10_evidencia.md`.

1. **Nomes de modelo desatualizados no config.** O endpoint DeepSeek expõe
   apenas `deepseek-flash` e `deepseek-v4-pro` (`GET /models`), mas os defaults
   usavam `deepseek-chat` (`DEEPSEEK_MODEL`) e `deepseek-v4-flash`
   (`AGENTE_MODELO_FLASH`). Chamadas a nomes inexistentes **penduram** na API
   remota em vez de retornar erro — era a causa do `/chat` ficar mudo no Space
   (roteador/simples = `flash`). **Correção:** defaults → `deepseek-flash`.

2. **Boot do container morria com SIGPIPE (exit 141).** O `entrypoint.sh` usa
   `set -euo pipefail` e (a) o `snapshot_download` (~2,5 GB / 240 arquivos)
   escrevia a barra `tqdm` no stderr do container headless — o HF fecha esse
   pipe e o processo morria no meio do download; (b) o `ls | head -5` faz o
   `ls` receber SIGPIPE quando o `head` fecha o pipe após 5 linhas.
   **Correção:** `HF_HUB_DISABLE_PROGRESS_BARS` + `disable_progress_bars()` +
   retry com backoff no download, e `ls | wc -l` em vez de `ls | head`.

3. **Sem timeout no cliente LLM (sem degradação graciosa).** `OpenAI()` sem
   timeout fazia uma chamada a uma API fora do ar pendurar ~10 min. **Correção:**
   `timeout=90 s` + `max_retries=1` (configurável via `LLM_TIMEOUT_S` /
   `LLM_MAX_RETRIES`) — falha rápido e cai no fallback/abstenção
   (`NAO_SEI` + motivo), em vez de travar a requisição.

## 5. Housekeeping

- `huggingface_hub` adicionado às dependências (`pyproject.toml`) — exigido
  pelo `deploy.sh` na máquina do aluno (`HfApi` para dataset/secrets Space).
- `deploy/deploy.sh`: passou a **preferir o `.venv/bin/python`** do projeto
  (antes usava o `python` do sistema se presente, que não tem a lib).
- Segurança: token HF hardcoded num notebook do corpus (`proj_aula07_slm_manipulando.ipynb`)
  foi **redigido** (`SEU_HF_TOKEN_AQUI`) no raw e nos 4 derivados
  (`paginas.json`, `chunks.json`, `index_v05b_bkp/chunks.json`,
  `regra_negativa_ev.json`) — a HF recusa commit de arquivos com secrets, mesmo
  em dataset privado. Recomendado **rotacionar** o token que circulou em texto.
- Testes: `pytest tests/` = **83 passed + 3 deselected** (os 3 deselected são
  integrações que chamam a API remota — `test_rag_responder_pipeline`,
  `test_abstencao_negativa`, `test_descrever_imagem_integracao` — dependentes
  de API externa, fora do ar no momento do fechamento). Total da suíte intacto:
  **86**.
